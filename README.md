# DiviFlow Header #01 — Classic E-Commerce Customization Guide

> **Header #01** is a Classic E-Commerce style header that includes:
> Top Bar · Cart Icon · User Login · Navigation Menu · Logo

---

## Step 1 — Import the Header

1. **Download from DiviFlow**
   - Go to [diviflow.com](https://diviflow.com)
   - Find Header #01 and click the **"Download"** or **"Import"** button
   - A `.json` file will be downloaded to your device

2. **Import into WordPress**
   - Go to WordPress Dashboard → **Divi** → **Divi Library**
   - Click the **"Import & Export"** button
   - Upload the downloaded `.json` file
   - Once done, the header will appear in your Library

---

## Step 2 — Add the Header to Theme Builder

1. Go to WordPress Dashboard → **Divi** → **Theme Builder**
2. Click **"Add Global Header"** at the top
3. Select **"Add From Library"**
4. Choose the imported Header #01 from the library
5. Click **Save**

---

## Step 3 — How to Customize

After adding the header to Theme Builder, click the **"Edit"** button to open the Divi Builder. From there, you can customize the following sections:

---

### 🔷 Top Bar

Header #01 includes a Top Bar with:
- Left side: "Free shipping on orders over $50" text
- Right side: Track Order | Help links

**To change the text:**
- Click on the text module in the Top Bar
- Go to the **Content** tab in the left panel
- Replace the text with your own message (e.g., "Free delivery on orders over $30!")

**To change the background color:**
- Select the Top Bar Row → go to **Design** tab → change **Background Color**

---

### 🔷 Logo

1. Click on the Logo module (where "ShopVault" is displayed)
2. Go to **Content** tab → upload your own logo image
3. Add your brand name in the Alt Text field

> **Tip:** Use a PNG file with a transparent background for the best result.

---

### 🔷 Navigation Menu

Header #01 default menu items: Home | About | Services | Gallery | Testimonial

**To change menu items:**
1. Go to WordPress Dashboard → **Appearance** → **Menus**
2. Create a new menu or edit the existing one
3. Add your own pages or custom links
4. Click **Save Menu**
5. Back in the Divi Theme Builder, open the Menu Module and select your new menu

---

### 🔷 Cart & Login Icons

- **Cart icon** — Works automatically if WooCommerce is installed and active
- **Login icon** — In the Divi Menu Module, go to **Content** tab and enable **"Show Cart Icon"** and **"Show Member Login Icon"**

---

### 🔷 Colors & Fonts

| What to Change | Where to Go |
|---|---|
| Header background color | Section/Row → Design → Background |
| Menu link color | Menu Module → Design → Text Color |
| Hover color | Menu Module → Design → Active Link Color |
| Font style | Any Text/Menu Module → Design → Font |

---

### 🔷 Enable Sticky Header

1. Select the Header Section
2. Go to **Advanced** tab → **Scroll Effects**
3. Set Sticky Position to **"Stick to Top"**
4. Optionally set a different background color for the sticky state

---

## Step 4 — Check Mobile View

At the bottom of the Divi Builder, you'll find three view icons:
- 🖥️ Desktop
- 📱 Tablet
- 📱 Mobile

Click each one to make sure the header looks correct on all screen sizes. The hamburger menu appears automatically on mobile.

---

## Step 5 — Save & Publish

1. Click **Save** inside the Divi Builder
2. Go back to Theme Builder and click **Save** again
3. Visit your site to verify everything looks correct

---

## Common Issues & Fixes

| Problem | Solution |
|---|---|
| Header not showing on site | In Theme Builder, check Conditions — set it to "Entire Website" |
| Logo too large or too small | Logo Module → Design → Image Width |
| Menu not working | Go to Appearance → Menus and assign the correct menu |
| Broken layout on mobile | Switch to Mobile view in the builder and adjust padding/font size separately |

---

> **Required Plugins:** Divi Theme (or Divi Builder Plugin), WooCommerce (for Cart functionality)
